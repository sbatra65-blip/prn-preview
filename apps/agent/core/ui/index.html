Add a network printer

For label printers with Ethernet or Wi-Fi. Find the IP address on the printer's self-test or network-settings print. Network printers take printer commands (TSPL, ZPL, EPL…).

Phone printing

Phones paired with this computer print here even when no browser is open. To pair: open LabelDesk on this computer, choose File → Print more → Print station, then Let the Print Agent receive, and scan the QR code with the phone.
